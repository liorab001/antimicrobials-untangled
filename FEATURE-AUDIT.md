The original opaque script injected by the previous hosting origin was removed. Tailwind, Font Awesome and the original public API integrations remain. `window.onload` startup was replaced by validated database-first startup to prevent page initialization racing database loading.

The compatibility seed is deliberate: the uploaded database did not include resistance surveillance, renal/HD/alternative-route references, or the executable pediatric calculation helpers. The seed preserves compatibility with that original database. The delivered version 1.1.1 stores those data in `referenceCollections`; pediatric calculations use a finite declarative arithmetic/template representation, with no database JavaScript or `eval`.

The source audit accounts for all original features. Matching behavior is intentionally governed by the new engine contract, so extracted regimen output need not be identical to the old heuristic parser. The supplied engine can reject source shapes the old parser summarized. Such branches stay visible as review notices and source evidence.

Focused validation used Chromium with mocked FDA/NIH/Europe PMC responses: startup and consent; a rendered drug card; resolved and unresolved engine-result displays; resistance dashboard, Gram filtering, count polling and OA paper display; import of the original database; rejection of an invalid database; and an expanded database adding a format, patient field, drug and resistance region. No application page errors occurred in the served-page flow. JavaScript syntax was checked. Public API availability and clinical content were not exhaustively tested. Direct local-file navigation was blocked by the managed browser's administrator policy, while file selection/import on the served page passed.

Dosing correction: focused checks against retrieved cefepime and penicillin V label records verified adult pneumonia, direct CrCl matching, missing-CrCl source options, linked renal-column adjustments, the Pseudomonas-specific schedule, pharyngitis, age exclusion, dialysis exclusion and pediatric weight limits. A VM integration check verified rendered dosage bullets and a 350-result visible-cache regression using an inexpensive fake interpreter. Browser retesting was unavailable in the managed Sites environment.

Renal/display patch: engine 1.0.2 and database 1.1.3 implement the user-configured qualitative normal-function rule without numerical CrCl substitution. Real cefepime and levofloxacin label checks verified the 90/89 threshold, direct CrCl precedence, concise deduplicated HAP/Pseudomonas output, full retained evidence, slider/preset parity, severe-screen ranking and dialysis exclusion. Focused checks used Node workers and the shipped UI functions in a VM; browser retesting remains unavailable in this managed Sites environment.
