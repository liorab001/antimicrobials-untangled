Academic Software Sandbox — Non-Clinical Use Only

1. NOT A MEDICAL DEVICE, AND NOT FDA NON-DEVICE CDS: Antimicrobials Untangled is an independent academic software portfolio and a document-inspection sandbox. It is not a certified medical device (MDSW) under Regulation (EU) 2017/745 or MDCG 2019-11. It is not offered as Non-Device CDS under FD&C Act § 520(o)(1)(E): that safe harbor is limited to recommendations intended for health care professionals, and this public page is an academic sandbox. It must never be used to diagnose, treat, cure, prevent, or guide prescribing for any real patient. A color on parsed text is an inspection flag. It is not a statement that a regimen is safe, standard, or appropriate.
2. EXPERIMENTAL TEXT PARSING: Bullet summaries, search interpretations, pathogen–syndrome indexes, renal text-branch highlights, and interaction flags are produced by experimental client-side text parsing. Parsing can omit, misclassify, or truncate the source. A missing flag is not a safety finding. Read the complete official monograph before treating any sentence as the label's meaning.

  • WHO and ECDC: Static resistance figures on the surveillance page are educational illustrations stored in this repository. 4. PRIVACY AND NETWORK DISCLOSURE:

The developer runs no backend server, sets no cookies, and keeps no account or search database.

This static site is hosted by GitHub, Inc., so a visit sends the browser's IP address to GitHub Pages.

A search or literature poll sends the IP address and the search text directly from the browser to api.fda.gov, NIH hosts including rxnav.nlm.nih.gov, and www.ebi.ac.uk, and the page loads an icon stylesheet from cdnjs.cloudflare.com. Those operators, not the developer, receive that traffic, including possible transfers outside the EEA.

Age, weight, sex, pregnancy, allergy, dialysis, and renal numbers are sample branch filters. They start at age 40 years and weight 70 kg. They stay in this browser and are not sent to the developer. If they describe a real person, they are health data. Leave the sample values in place.

FDA Monograph Branch Explorer. These values choose which monograph sentences are shown. eGFR is entered in mL/min/1.73 m² and CrCl is entered separately in mL/min. eGFR is not converted into CrCl. eGFR 90–130 with no dialysis selects ordinary-function label text. Outside that band, CrCl-specific sentences stay hidden until a CrCl is typed. Dialysis shows the label’s dialysis sentences when the monograph contains them. Nothing on this page estimates clearance or calculates a medicine amount. The fields start at sample values. Do not replace them with a real person's age, weight, sex, pregnancy, allergy, dialysis, or renal function.
